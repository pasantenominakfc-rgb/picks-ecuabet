# Material de trabajo

- `datos_reales/`: CSV reales de football-data (temporadas 2025/26 y 2026/27 hasta el 08/11/2026) usados en la prueba de 30 días.
  Para repetirla: `python tests/ultimos30.py docs/datos_reales`
- `simulacion30.json`: resultado de esa prueba (también se ve en la app, en "Rendimiento").
- `vista_previa/`: partidos reales del 22 y 23/11/2026 leídos de Forebet, más el script que armó la vista previa.
- `diseno.md` y `prueba-real-30-dias.md`: decisiones de diseño y resultados.
